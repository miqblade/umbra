# Umbra

Рабочее пространство для SEO-работы и работы с несколькими аккаунтами: зашифрованный сейф, профили браузеров с отдельным сетевым окружением (свой туннель, kill-switch, проверка IP), собственные модули (инструменты), паника и уничтожение одной кнопкой.

Статус: ранний каркас. Сделано ядро (`src/Umbra.Core`): вход (пароль / пароль+код / без входа, 5 попыток), криптография, формат `umbra.dat`, уничтожение сейфа, система модулей. Интерфейс и движки рабочего стола — следующие этапы, см. `docs/ARCHITECTURE.md`.

Сборка и проверка: `dotnet build` и `dotnet run --project tests/Umbra.Tests`. Сторонних пакетов нет намеренно.
